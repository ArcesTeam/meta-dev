# Meta 项目阶段性路线图与版本规划

> 本文档汇总了 Meta 项目的宏观设计方向与版本迭代路线，适用于长期战略规划与阶段性开发目标归档。
>
> **Meta 项目简述**：Meta 是一个面向 Minecraft
>
的数据驱动与行为组合平台，其核心理念是通过元数据描述驱动游戏数据与逻辑的构建，未来目标是发展为一个具备“低代码甚至零代码能力”的游戏开发辅助工具。最终愿景是脱离
> Minecraft，转化为通用的元游戏引擎构建平台。
>
> 作者：John

---

## ✅ v0：基础数据驱动（当前阶段）

> 「构建统一的注册结构，完成数据的抽象、收集、注入、生成等能力」

- 提供基础的元数据模型（Item、Block、Lang、Model 等）
- 实现注解驱动的数据声明方式
- 构建元数据注册表体系，集中式注册管理
- 支持自定义数据生成（Lang、Model、Blockstate 等）

涉及模块：`meta-api`、`meta-core`、`meta-runtime`、`meta-datagen`

---

## 🚧 v1：可扩展的元数据生态

> 「允许开发者在 Meta 框架外自由扩展其数据模型，实现与 Minecraft 注册体系的等价处理」

- 元数据类型 {@link MetadataType} 完全可扩展
- 支持诸如“技能”、“科技树”等游戏逻辑元的接入
- 支持通用注册表模拟与统一注册行为
- 数据可序列化/反序列化用于生成与持久化

---

## 🔬 v2：行为元数据与组合驱动

> 「将所有游戏逻辑抽象为最小化的行为元，实现高度组合式开发模型」

- 定义行为元（Tickable、Interactable、Inventory 等）
- 支持行为元挂载与运行时上下文执行
- 提供行为注册、注入、调度能力
- 支持组合能力依赖关系与动态组合模式

---

## 🎨 v4：可视化设计与 JSON 编辑器支持

> 「提供游戏内外的零代码可视化设计器，简化元数据组合流程」

- 提供 Web UI / In-game UI 元数据编辑器
- JSON 导入/导出与热加载机制
- 所见即所得数据编辑与预览
- Blueprint 系统支持模板保存与复用

---

## 🧠 v5：低代码 / 零代码平台化工具

> 「转变为开发工具平台，使 Mod 制作成为更广泛人群可触及的创造行为」

- 提供从元数据设计 → mod 导出的完整工具链
- 内建能力模块与可组合能力系统（如方块交互、GUI、逻辑组件）
- 支持脚本拓展机制（如 KubeJS 风格）

---

## 🪐 v6：架构独立，构建轻量级数据引擎

> 「脱离 Minecraft，成为通用型游戏逻辑描述平台，迈向“元游戏引擎”目标」

- 抽象运行模型，替代 Minecraft 引擎依赖
- 构建通用对象/行为系统支持
- 导出为 JSON/DSL 等数据包供其他引擎解析
- 模拟独立游戏编辑器架构
